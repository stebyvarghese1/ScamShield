## &nbsp;&nbsp;&nbsp;` 02 `&nbsp;&nbsp; THE IDEA

</div>

<br>

> ### *"Not just 'Is this safe?'. A Personal Cybersecurity Assistant — unmasking deceptive tactics and explaining the exact threat signals before you interact."*

<br>

**ScamShield** bridges the gap between complex enterprise threat intelligence and everyday internet users. Instead of cryptic security jargon or raw blacklists, ScamShield breaks down *why* a message, URL, QR code, or screenshot is dangerous and provides clear, non-technical actions to prevent fraud.

<br>

<div align="center">

```
  ┌─────────────────────────────────────────────────────────────────┐
  │                                                                 │
  │   🚫  ZERO-DB ARCHITECTURE   Pure in-memory ephemeral sessions │
  │   🧠  EXPLAINABLE AI        Clear 'Why' and safe recommendations│
  │   ⚡  10 THREAT INTEL FEEDS  Live multi-engine consensus radar  │
  │                                                                 │
  └─────────────────────────────────────────────────────────────────┘
```

## &nbsp;&nbsp;&nbsp;` 07 `&nbsp;&nbsp; GETTING STARTED

</div>

<br>

**Prerequisites** — Python `3.10+` · Git

<br>

**Step 1 — Clone**
```bash
git clone https://github.com/stebyvarghese1/scamshield.git
cd scamshield
```

**Step 2 — Environment**
```bash
# Windows
python -m venv venv
.\venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt
```

**Step 3 — Configure (Optional)**
```bash
cp .env.example .env
```
*(ScamShield's heuristic engine works out of the box even with no API keys).*

**Step 4 — Launch Locally**
```bash
python run.py
```
> ScamShield automatically opens in your browser at `http://127.0.0.1:8000`.
